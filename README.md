# Holberton School – Core Engineering (Python)

A curated collection of Python projects and exercises completed as part of the **Holberton School Core Engineering** curriculum.

This repository is organized by topic areas (fundamentals, OOP, and advanced Python). Each module contains hands-on tasks focused on building strong software engineering foundations.

## Repository structure

- `python_fundamentals/` – Introductory Python concepts and core language features
- `python_oop/` – Object-oriented programming principles and practice
- `python_advanced/` – More advanced Python topics and patterns

## Getting started

### Prerequisites

- Python 3.x
- A Unix-like environment (Linux/macOS/WSL recommended)

### Clone

```bash
git clone https://github.com/McPe4ce/holbertonschool-core-engineering.git
cd holbertonschool-core-engineering
```

## How to use this repository

1. Navigate into a module directory (for example, `python_fundamentals`).
2. Read the module’s `README.md` for learning goals and task instructions.
3. Run the Python scripts as needed:

```bash
python3 <script_name>.py
```

## Notes

- This repository is primarily educational and mirrors Holberton School-style project requirements.
- Some tasks may depend on project-specific constraints (file naming, output formatting, etc.).
